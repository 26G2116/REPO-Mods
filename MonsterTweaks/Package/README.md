# MonsterTweaks

モンスターの挙動を変える MOD(23 体の個別の強化と、全モンスター共通の設定)。敵の動きはホストが計算しているので、**基本はホストだけ導入すれば全員に効く**。
できるだけゲーム本来の物(卵の爆発、ロールの杖の効果、本物の敵の分身)を使うので、MOD なしの参加者の画面でもそれらしく見える。
設定は敵ごとに分かれていて、それぞれ「有効」で ON / OFF できる。REPOConfig を使えばゲーム中に変更でき、すぐ反映される。

| 敵 | 変更内容 |
|---|---|
| 1. エルサ | 覚醒までの時間、覚醒している時間、ターゲットが倒れたら覚醒したまま最寄りの生存者を狙う |
| 2. APEX プレデター | 怒っているときの速度と時間、怒りが終わったら人類美術館の卵の爆発で自爆(卵の数で範囲を調整) |
| 3. トラッジ | 追いかける・うろつく速度、前隙、攻撃後に動き出すまでの時間、攻撃を始める距離 |
| 4. シャドーチャイルド | 範囲内で貴重品・アイテムをつかんでいると見つかる。チャージ完了時、範囲内で物を持つ全員を攻撃 |
| 5. ローブ | 範囲内のプレイヤーの位置を常に把握、死角への回り込みと奇襲、諦めない、突進の速度 |
| 6. バースデーボーイ | スタン無効(共通設定)、つかまれたら即激怒 |
| 7. ルーム | スタン無効(共通設定)。叩きつけでロールの杖・魔法学校のクリスタルと同じロール効果(5 秒、貴重品にも) |

| 11. ハートハガー | スタン無効。認識範囲と魅惑の霧の範囲を拡大 |
| 12. アニマル | スタン無効。視界に入っている人のうち、転んでいない人を優先して狙う |

## 全モンスター共通の設定
31 種類すべてのモンスターに、個別に「スタン無効」と「移動速度倍率(共通)」がある。
個別の変更がある敵(1〜23)はそのセクションに、それ以外は「モンスター: ○○」のセクションにある。
移動速度はナビメッシュの速さと体の追従速度にかかる(飛びかかり・空中移動など、ナビメッシュを使わない動きには効かないことがある)。
1〜23 の敵は、そのセクションの「有効」を OFF にすると共通設定も効かなくなる。

## MOD なしの参加者の画面での見え方
- APEX プレデターの自爆(卵)、ルームのロール効果、クリーンアップクルーの分身、シャドーチャイルドの複数攻撃: **そのまま見える**
- トラッジの前隙: 攻撃のタイミングは全員に効くが、MOD なしの人の画面では振り下ろしのモーションが元の速さのまま
- シャドーチャイルドの複数攻撃: 触手が伸びるのは本来の相手だけ(ほかの人は引き寄せられてダメージを受ける)
- ティックの反撃とスタン、ウーグリーのテレポート、バンガーのダメージ、ボウタイの回転、シェフの前隙: **そのまま効く**
- ヘッドマンが呼び出すバンガー、ヒドゥンの運ぶ先と電池、リーパーの狙い: **そのまま効く**
- ピーパーの追加のターゲット: MOD なしの人はダメージだけ受ける(カメラが吸い寄せられる演出などは出ない)
- バンガーの導火線: 爆発は同時に起きるが、MOD なしの人の画面では導火線の見た目が本来の速さのまま
- 卵・ロールの杖が見つからないとき(シングルプレイのロール効果など)は MOD の代わりの効果になり、それは MOD なしの人には見えない

## 動作確認用
設定「0. 全体 → 詳しいログ」を ON にすると、乗り換え・自爆・奇襲・入れ替えなどをしたときに BepInEx のログへ出る。
