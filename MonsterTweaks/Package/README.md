# MonsterTweaks

8 体の敵の挙動を変える MOD。敵の動きはホストが計算しているので、**基本はホストだけ導入すれば全員に効く**。
設定は敵ごとに分かれていて、それぞれ「有効」で ON / OFF できる。REPOConfig を使えばゲーム中に変更でき、すぐ反映される。

| 敵 | 変更内容 |
|---|---|
| 1. エルサ | 覚醒までの時間、覚醒している時間、ターゲットが倒れたら最寄りの生存者を狙う |
| 2. APEX プレデター | 怒っているときの速度と時間、怒りが終わったら広範囲に自爆 |
| 3. トラッジ | 追いかける・うろつく速度、前隙、攻撃後に動き出すまでの時間、攻撃を始める距離、攻撃範囲 |
| 4. シャドーチャイルド | 範囲内で貴重品・アイテムをつかんでいると、見ていなくても見つかる |
| 5. ローブ | 範囲内のプレイヤーの位置を常に把握、死角への回り込みと奇襲、諦めない、突進の速度 |
| 6. バースデーボーイ | スタン無効、つかまれたら即激怒 |
| 7. ルーム | 叩きつけの衝撃で、周りのプレイヤーを転がす(ロールドローンのような回転) |
| 8. クリーンアップクルー | 顔爆弾を投げたあと、爆発を待たずに次の頭を再生して投げる |

## 参加者も入れたほうがよいもの
- **APEX プレデターの自爆**: ダメージは全員に入るが、爆発の見た目と音は MOD を入れた人にしか出ない
- **トラッジの攻撃範囲**: ダメージの当たり判定は各自の PC で計算するので、参加者にも同じ設定で入れたときだけ広がる
  (吸い込みの範囲と前隙・後隙はホストだけで効く)
- **クリーンアップクルーの追加の顔爆弾**: MOD を入れた人にしか見えないため、既定では部屋の全員が入れているときだけ動く

## 動作確認用
設定「0. 全体 → 詳しいログ」を ON にすると、乗り換え・自爆・奇襲などをしたときに BepInEx のログへ出る。
