# FloorRoles(階層毎選択型役職)

**ホストだけ**が入れれば、MOD なしの参加者にも効きます(ゲーム本来の通信だけを使います)。

## トラック(ショップのあと)
- トラックに入ると、次のマップを先に抽選し、トラックのモニターに「次のマップ」と役職ごとの報酬を書きます。
- 人数分の**ロールオーブ**が各プレイヤーの前に出ます。
- 出発したとき、ロールオーブを**1 つだけ**インベントリに入れている人は、入れたスロットの役職になります。
  - スロット 1 = **運搬**、2 = **戦闘**、3 = **特殊**
  - 0 個、または 2 個以上入れている人は役職なし(報酬なし)
- 出発(モニターのチャット)は**ホストだけ**ができます。ほかの人がやると「出発はホストだけ！」としゃべります。

## ステータス報酬
役職ごとに 3 種類のアップグレードから 2 つを抽選し(トラックの時点でモニターに表示)、次のレベルの開始時にもらえます。

| 役職 | 候補 |
|---|---|
| 運搬 | スタミナ、しゃがみ回復、力 |
| 戦闘 | 体力、スプリント速度(上限 4)、射程 |
| 特殊 | 追加ジャンプ、タンブルウイング、タンブル発射(上限 2) |

- 上限に達している報酬は、同じ役職の残りの 1 つに差し替えます。
- もらった報酬は、その人がしゃべって知らせます(例:「運搬: スタミナ+1、力+1」)。
- 役職特性・マップごとの追加特性は、まだありません(あとで追加予定)。

## ショップの所持金
- ショップに入ると、チームのお金を人数で分けた**金袋(小)**が抽出口のまわりに出ます(例: 7 人で 100K なら 15K × 2 と 14K × 5。最大 20 個)。ショップの中の金袋は壊れません。
- 金袋を**最初につかんだ人**の所持金になり、金袋は消えます。
- 商品は、その商品に**最後に触った人**の所持金で買います。足りない商品は買われず、精算口に残ります。
- 所持金を持った人が**死ぬ**と、その場に所持金分の金袋を落とします。**抜けた**ときも最後にいた場所に落とします。
- **タンブル**中は、0.5 秒ごとに 1K の金袋を落とします(ほかの人に渡す方法)。
- 使わなかった所持金はチームのお金に戻り、次のショップでまた分けられます。

## 決闘(ショップだけ)
- 同じ商品を 2 人以上でつかんだまま 3 秒たつと、全員が「いざ尋常に、勝負！」→「1D100」→ 出た数字 をしゃべります。
- **いちばん大きい数字**の人が自爆します(同じ数字なら、その人たちで振り直し)。自爆した人の所持金は金袋になって落ちます。

## 店のアップグレード
- マップの人数確認 × 4、デスヘッドバッテリー × 1 を必ず並べ、それ以外のアップグレードから人数分(最大 5 個)をランダムに並べます。
- 店に「アップグレードを置ける場所」が足りないときは、残りをほかのアップグレードのそばに出します(棚から落ちることがあります)。

## ダイス(/r)
- チャットで `/r` と打つと、その人が「1D100 Start!」→「出た数字!」としゃべります。
- **1〜5** なら続けて「critical!」としゃべり、**HP が 100 回復**します。
- **96〜100** なら「fumble!」としゃべり、**自爆**します。
- MOD なしの人が打っても動きます。打った「/r」は、ほかの人の画面に一瞬出ますが、すぐ次のセリフで上書きされます。
- 振れるのは、ゲームを遊んでいる最中(レベル・ショップ・トラック)です。設定でレベル中だけにもできます。

## 設定
すべて設定ファイル(`shunm.FloorRoles.cfg`)で ON / OFF や数値を変えられます。
