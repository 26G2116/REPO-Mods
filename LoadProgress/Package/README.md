# LoadProgress

マルチプレイのロード中に、全員のロードの進み具合を 10 段階で表示する。
ロードが始まると自動で表示され、終わると自動で閉じる。

| # | 段階 |
|---|---|
| 1 | 中継シーン到着 |
| 2 | キャラ生成 |
| 3 | マップ生成(ホスト) |
| 4 | マップ受信 |
| 5a | 貴重品受信 |
| 5b | NavMesh 構築 |
| 6 | スポーン |
| 7 | 敵受信 |
| 8 | 生成完了 |
| 9 | 演出終了 |

- ホストが導入: 全員の進捗が見える(MOD なしの人は 5a/5b などを推定で表示)
- 参加者が導入: 自分の進捗は全段階、他人はゲームが共有している範囲 + ホストや他の導入者から届いた情報を表示
