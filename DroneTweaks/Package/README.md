# DroneTweaks

ドローン・オーブを変える MOD。**基本はホストだけ導入すれば全員に効く**(店の品ぞろえ・ドローンの狙い・電池・復活はホストが計算している)。

## 1. 店に出すアイテム
ゲームから削除されたドローン・オーブ(データはゲームに残っている)を、店に並ぶ候補に戻す。アイテムごとに ON / OFF できる。

| アイテム | 効果(ゲーム本来のもの) |
|---|---|
| ヒーラードローン | くっついた人を回復する(この MOD で復活もできるようになる。下の 2.) |
| フェザーオーブ | 範囲内の物とプレイヤーを軽くする(この MOD で「貴重品の価値を回復する」効果に変わる。下の 4.) |
| ヒーラーオーブ | 範囲内の人を回復する |
| 不滅オーブ(破壊不能オーブ) | 範囲内の物を壊れなくする(この MOD でプレイヤーも無敵になる。下の 3.) |
| マグネットオーブ | 範囲内の物を引き寄せて一緒に運ぶ(この MOD で「貴重品をアイテムに変える」能力が増える。下の 5.) |
| ロールオーブ | 範囲内の物を回転させる |
| ロールドローン | (今も売られているアイテム。OFF にすると店に出なくなる) |

- 削除されたアイテムはゲームのアイテム一覧にも追加されるので、RepoAdminMenu などのアイテム召喚からも出せる(店の設定が OFF でも出せる)
- 出したアイテムは MOD なしの参加者の画面にも出て、ゲーム本来のプログラムどおりに動く

## 2. ヒーラードローン
- **倒れた人を復活させる**: 起動中、ドローンから 2.5m 以内(壁越しは除く)に倒れた人の頭があれば生きている人より優先してくっつき、電池を使って復活させる
  (初期値: 電池 20% を 4 秒かけて使うと復活、復活後の体力 50)
  復活の直前に頭を床の少し上で 0.5 秒止めてから復活させる(床にめり込んだ頭から復活して床を抜けないように)
- 回復中の人が倒れたときや、復活させたあとも、ドローンを止めずにそのまま次の相手を探す
- **回復の電池効率**: 回復した分だけ電池が減る(初期値: 電池満タンで 250 回復)。ビームを出しているだけでは減らない
- 回復の速さ(2 秒ごとに 10)はゲーム本来のまま

## 3. 不滅オーブ
- 範囲内の物(貴重品など)が壊れない(ゲーム本来の効果)
- **範囲内のプレイヤーが無敵になる**: 減った体力をすぐ元に戻し、敵や物に当たっても転ばない(自分で転ぶ操作はできる)
  - ホストが入れていれば、MOD なしの人にも効く
  - 体力は「一度減ってから、ホストがすぐ回復で戻す」しくみ(ダメージはダメージを受ける人の PC で計算されるため)。
    ダメージの画面効果は出る。**一撃で体力が 0 になる攻撃は防げない**
  - 敵につかまれる・運ばれるなどの特殊な攻撃は止めない
- **電池の持ち**: 起動している間、電池満タンで 60 秒使える(初期値)

## 4. フェザーオーブ
- **範囲内の貴重品の価値を回復する**: 1 秒ごとに元の額の 1% ずつ、元の額まで戻す(初期値)
  - 価値の回復はホストが計算して全員に送るので、MOD なしの人の画面の値段もそろう
- **電池の持ち**: 起動している間、電池満タンで 120 秒使える(初期値)
- 元の効果(物とプレイヤーを軽くする)は止める。設定「元の効果(軽くする)も残す」を ON にすると両方出る
  - プレイヤー自身が軽くなる効果だけは各自の PC で計算されるので、MOD なしの人には元のまま出る

## 5. マグネットオーブ
元の効果(物を引き寄せて一緒に運ぶ)はそのままで、**貴重品をアイテムに変える**能力が増える。

- 使い方: 起動したオーブの範囲内に貴重品が **5 個以上**ある状態が **2 秒**続くと発動する(オーブは持っていても置いていてもよい)
- 発動すると、範囲内の貴重品とオーブが壊れ、貴重品の合計金額に応じたアイテムが出る
- **1 レベルに 1 回だけ**(全オーブ合計)。壊れたオーブは、次のレベルでまたトラックに出る
- 出たアイテムは**そのレベル限り**(次のレベルのトラックには出ない)

| 貴重品の合計金額 | 出るアイテム |
|---|---|
| $3,000 以下 | 回復パック小(25)・爆発地雷・手榴弾 のどれか 1 つ |
| $3,001〜$6,000 | リチャージドローン・不滅ドローン・ボルトザップ のどれか 1 つ |
| $6,001〜$9,999 | ヒーラードローン・ショットガン・フォトンブラスター のどれか 1 つ |
| $10,000〜$19,999 | C.A.R.T.(大きいカート)+ C.A.R.T. レーザー + 剣 |
| $20,000 以上 | C.A.R.T. + C.A.R.T. キャノン + ガン ×4 + ヒーラードローン ×2 |

- アイテムはオーブの近くの空いている床(壁・物・人と重ならず、壁越しでない場所)に、重ならないように出す
- カートが出るときは、ほかのアイテムをカートの中に重ならないように並べる。入りきらないもの(剣など)はカートの近くの床に出す
  - C.A.R.T. レーザー / キャノンは、起動したときと同じ向き(立てて、砲口がカートの前)でカートの後ろの端に置いた状態で出す。カート武器は「カートの中にあると起動する」しくみなので、そのまま使える。砲身の下にも低いアイテムを並べる
- 回数・必要な数・発動までの時間・「置いているときだけ発動する」(初期値 OFF)は設定で変えられる
- ゲームは「購入していないアイテムを使い切ったとき」に、同じ種類の購入済みアイテムを 1 個減らしてしまう。
  報酬のアイテム(回復パック・地雷・手榴弾など)ではそれが起きないようにしている

## 6. 店の値段
ドローン・オーブ 13 種類の店の値段を、アイテムごとに設定できる(単位 K = $1,000)。**0 = ゲーム本来の値段**(初期値)。

| アイテム | ゲーム本来 | アイテム | ゲーム本来 |
|---|---|---|---|
| リチャージドローン | $14〜18K | リチャージオーブ | $22〜30K |
| フェザードローン | $14〜18K | フェザーオーブ | $14〜18K |
| ヒーラードローン | $22〜30K | ヒーラーオーブ | $72〜100K |
| 不滅ドローン | $22〜30K | 不滅オーブ | $22〜30K |
| ロールドローン | $8〜12K | マグネットオーブ | $72〜100K |
| 無重力ドローン | $22〜30K | ロールオーブ | $14〜18K |
| | | 無重力オーブ | $38〜48K |

- 設定した値段は固定(ランダムにならない)。値段はホストが決めて参加者に送るので、MOD なしの人の画面にも同じ値段が出る
- 店に並ぶ候補を選ぶとき、ゲームは「今の所持金で買える物」を優先する。この判定にも設定した値段が使われる
- ゲーム中に変えた場合は、次に店に入ったときから反映される

## 動作確認用
設定「0. 全体 → 詳しいログ」を ON にすると、アイテムの追加・頭へのくっつき・復活をしたときに BepInEx のログへ出る。
